# Olá, eu sou o Lucas Vergara 👋

Estudante do **8º semestre de Ciência da Computação**, em São Paulo.

## Sobre mim

Gosto de construir sistemas back-end bem organizados, com responsabilidades claras entre as camadas, e de explorar como modelos de linguagem podem resolver problemas reais. Meus projetos vão de uma API REST containerizada a um chatbot de WhatsApp com IA executada localmente.

## Áreas de interesse

- Desenvolvimento back-end e APIs REST
- Aplicações com inteligência artificial e modelos de linguagem (LLMs)
- Sistemas distribuídos e containerização

## Projetos

### [API de Pedidos](https://github.com/LucasAVerg/APIPedidos-1-final)
API REST para gestão de pedidos, construída em arquitetura de camadas (Controller, Service e Repository) com **FastAPI** e **PostgreSQL** e totalmente containerizada com **Docker Compose**. Trabalho em grupo da disciplina Desenvolvimento de Sistemas Distribuídos.

### Chatbot para clínica oftalmológica
Chatbot de WhatsApp em **Node.js** que usa um modelo de linguagem local (**Ollama**) para fazer triagem de pacientes, tirar dúvidas e encaminhar agendamentos, com transferência para atendimento humano quando necessário. Projeto individual, desenvolvido sob encomenda.
